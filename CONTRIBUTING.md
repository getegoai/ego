# Contributing to Ego

Ego is an early project developed through public issues, commits, and pull requests. This initial publication contains definitions and a roadmap; the existing implementation is being prepared for import.

- Use [issues](https://github.com/getegoai/ego/issues) for use cases, bugs, design questions, or a proposed change. Explain the problem and the result you want.
- Keep pull requests focused. Describe what changed and any checks you actually ran. Unfinished work is welcome as a draft PR.
- Once code is imported, use its existing checks and record relevant failures. Documentation changes do not need a new test framework.
- AI-assisted contributions are welcome. The contributor remains responsible for understanding the change, its source, and its stated results.
- Keep credentials, personal records, and materials you lack permission to share out of issues and pull requests.

Contributions to the current original documentation are under CC BY 4.0. Future code contributions follow the license stated for that code when it is introduced. Credit sources and retain third-party notices.
