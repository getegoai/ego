# Contributing to Ego

Ego is an early project developed through public issues, commits, and pull requests. The existing EgoBase/Data Core implementation and its continuous development history are included alongside the project definition and roadmap.

- Use [issues](https://github.com/getegoai/ego/issues) for use cases, bugs, design questions, or a proposed change. Explain the problem and the result you want.
- Keep pull requests focused. Describe what changed and any checks you actually ran. Unfinished work is welcome as a draft PR.
- For Data Core changes, run the existing tests described in its README and record relevant failures. Documentation changes do not need a new test framework.
- AI-assisted contributions are welcome. The contributor remains responsible for understanding the change, its source, and its stated results.
- Keep credentials, personal records, and materials you lack permission to share out of issues and pull requests.

Contributions to the current original documentation are under CC BY 4.0. Data Core code, tests, schemas, configuration, and sample-fixture contributions use Apache-2.0, as stated in the root license scope and component LICENSE. Credit sources and retain third-party notices.
